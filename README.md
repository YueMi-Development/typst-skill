# Typst LLM Skill Collection

LLM skills for [Typst](https://github.com/typst/typst) typesetting (0.14+).

## Skills

| Skill | Description | Author | Source | License |
|---|---|---|---|---|
| typst | Core Typst typesetting: set/show rules, page layout and styling, math typesetting, tables and figures, custom functions, citations and bibliography, Quarto integration. Includes topic reference files under `references/`. | Ulrich Atz | [statzhero/typst-skill](https://github.com/statzhero/typst-skill) | CC-BY-4.0 |
| typst-touying | Slide presentations with the Touying framework: built-in themes (simple, university, metropolis, aqua, dewdrop, stargazer), animations via `#pause` and `#meanwhile`, multi-file presentations, CeTZ/Fletcher diagram integration. Based on Touying 0.7.3. | Ulrich Atz | [statzhero/typst-touying-skill](https://github.com/statzhero/typst-touying-skill) | CC-BY-4.0 |
| typst-cetz | Diagrams with CeTZ (TikZ-inspired drawing for Typst): coordinate systems, drawing primitives, styling, anchors, marks, trees, and plotting. | Ulrich Atz | [statzhero/typst-cetz-skill](https://github.com/statzhero/typst-cetz-skill) | CC-BY-4.0 |
